# SCENARIO-REVIEW: 냉장고 관리 웹 앱

검수자가 화면에서 눈으로 확인할 시나리오 표다. PRD 의 Must 완료 조건마다 한 줄이고, 상태가 바뀌는 시나리오의 "새로고침 뒤" 줄은 아래 별도 섹션에 모았다.
근거: [PRD.md], [USER-WORKFLOW.md], [SCREEN-SPEC.md], [API-SPEC.md], [DECISIONS.md]. 

## 읽는 법

- 열: 번호 · 시나리오 · 행동 · 기대 결과 · 근거 · 실제 결과 · 판정
- 근거는 요구사항 ID(R-, US-), 결정 번호(D-), 시나리오 번호(USER-WORKFLOW)다.
- 판정 값은 `통과 / 차이 / 발견 기록` 중 하나다. 
- 새로고침 = 브라우저 새로고침. 

## 기본 메시지 

| 메시지 | 기본 문구 | 나오는 때 |
|---|---|---|
| 입력 오류 | 입력한 내용을 확인해 주세요. | 이름이나 기한이 비었을 때, 수량 · 단위가 비었거나 수량이 0 이하 · 숫자가 아닐 때, 기한이 오늘보다 과거일 때, 구매일이 기한보다 뒤일 때 (SC-04 · 05 · 09 · 10 · 14 · 17 · 20 · 21 · 24) |
| 바꿀 수 없음 | 이 식품은 그렇게 바꿀 수 없습니다. | 지난 식품을 규칙표에 없는 이름으로 바꾸거나, 지난 식품의 보관 방법을 바꿨는데 새 기한이 오늘보다 뒤가 되지 않을 때 (SC-18 · 26) |
| 저장 실패 | 저장하지 못했습니다. 잠시 뒤 다시 시도해 주세요. | 등록 · 수정 · 보관 방법 변경 · 다 먹음 · 버림 · 삭제가 저장되지 않았을 때 (SC-06 · 11 · 22 · 28 · 32 · 49) |
| 없는 식품 | 이미 처리되었거나 없는 식품입니다. | 다른 곳에서 이미 지우거나 처리한 식품에 요청이 갔을 때 (D-008) |
| 빈 홈 | 아직 식품이 없습니다. 첫 식품을 등록해 보세요. | 홈에 보일 식품이 하나도 없을 때. 식품 등록 버튼이 같이 보인다. (SC-31 · 36 · 48) |
| 불러오기 실패 | 식품을 불러오지 못했습니다. 다시 시도해 주세요. | 홈을 열 때 식품 목록을 못 가져왔을 때 (SC-37) |

정상이 아닐 때 공통으로 지켜야 하는 것 (SCREEN-SPEC 0절 · 6절, USER-WORKFLOW 시나리오 8)

- 입력 오류는 입력칸 옆에 보이고, 저장 · 수정 · 처리 · 삭제 · 불러오기 실패는 화면 위에 보인다.
- 아무것도 바뀌지 않는다. 식품이 만들어지거나 바뀌거나 지워지지 않는다.
- 입력한 내용은 그대로 남고, 버튼은 다시 누를 수 있게 돌아온다.
- 계속 실패하면 같은 메시지가 계속 보인다. 문의 방법 같은 추가 안내는 없다.

## 새로고침 뒤

위 표에서 상태가 바뀌는 시나리오를 한 뒤 브라우저를 새로고침해서 확인하는 줄이다. 각 줄은 시나리오 열에 적은 앞 줄을 한 직후에 이어서 한다.

| 번호 | 시나리오 | 행동 | 기대 결과 | 근거 | 실제 결과 | 판정 |
|---|---|---|---|---|---|---|
| SC-50 | 새로고침 뒤: 식품 등록 (SC-01 이어서) | 등록하고 새로고침한다. | 등록한 식품의 막대가 그대로 남아 있다. | R-001, 시나리오 1, A-12 | | |
| SC-51 | 새로고침 뒤: 직접 등록 (SC-07 이어서) | 직접 등록하고 새로고침한다. | 직접 적은 기한의 막대가 그대로 남아 있다. | R-003, 시나리오 2 | | |
| SC-52 | 새로고침 뒤: 정보 수정 (SC-12 이어서) | 수정을 저장하고 새로고침한다. | 고친 내용이 그대로 남아 있다. | R-004, 시나리오 4 | | |
| SC-53 | 새로고침 뒤: 보관 방법 변경 (SC-23 이어서) | 저장하고 새로고침한다. | 바뀐 보관 방법과 새 기한이 그대로다. | R-005, 시나리오 5 | | |
| SC-54 | 새로고침 뒤: 삭제 (SC-29 이어서) | 삭제하고 새로고침한다. | 삭제한 식품이 돌아오지 않는다. | R-006, 시나리오 7 | | |
| SC-55 | 새로고침 뒤: 다 먹음 · 버림 (SC-44 · 45 이어서) | 처리하고 새로고침한다. | 처리한 식품이 홈에 돌아오지 않는다. | R-011, 시나리오 6 | | |
