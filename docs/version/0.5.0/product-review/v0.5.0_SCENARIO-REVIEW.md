# SCENARIO-REVIEW: 냉장고 관리 웹 앱

검수자가 화면에서 눈으로 확인할 시나리오 표다. v0.5.0 에서 **새로 생기거나 바뀐 기능만** 넣었다 (R-029 ~ R-046). 가입 · 등록 · 기록 · 되돌리기 같은 이어받은 기능은 v0.4.0 검수에서 이미 확인해 다시 쓰지 않았다.
근거: [PRD.md](../../../../PRD.md), [SCREEN-SPEC.md](../../../../SCREEN-SPEC.md), [DECISIONS.md](../../../../DECISIONS.md) (모두 v0.5.0). 이전 버전의 같은 문서는 `docs/version/0.4.0/product-review/` 에 있다.

## 읽는 법

- 열: 번호 · 시나리오 · 행동 · 기대 결과 · 근거 · 실제 결과 · 판정
- 근거는 스토리 번호(US-), 결정 번호(D-)다.
- 번호는 v0.4.0 문서에서 이어서 붙였다 (SC-132 다음이 SC-133).
- 실제 결과와 판정 열은 검수하면서 채운다. 아직 검수 전이라 `-` 와 `미검수` 로 두었다.
- 판정 값은 `통과 / 차이 / 발견 기록` 중 하나다. 검수 전에는 `미검수` 다.

## 새 메시지

| 메시지 | 기본 문구 | 나오는 때 |
|---|---|---|
| 입력 중 이동 | "입력한 내용이 사라진다"는 확인 창 | 정보 고치기에서 값을 고치다가 아래 탭을 눌렀을 때 |
| 사진 읽기 실패 | AI 가 응답하지 못했어요. 다시 시도해 주세요. | 사진 읽기에서 AI 가 응답하지 못했을 때 |
| 조언 실패 | 구현 단계에서 정한 쉬운 오류 문구 | 기록 화면에서 조언을 받지 못했을 때 |
