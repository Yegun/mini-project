# BUSINESS-RULE-REVIEW: 냉장고 관리 웹 앱

[DECISIONS.md](../../../../DECISIONS.md) 에서 v1.0.0 에 새로 생긴 결정(D-193 ~ D-197) 중 **규칙으로 확인해야 하는 것만** 골라 [SCENARIO-REVIEW](v1.0.0_SCENARIO-REVIEW.md)와 같은 열로 정리한 검수 표다. 화면 동작은 SCENARIO-REVIEW 에서 보므로 여기서는 비밀 정보 · 설정 · 주소 연결을 본다.
이전 버전의 같은 문서는 `docs/version/0.5.0/product-review/` 에 있다.

## 읽는 법

- 열: 번호 · 시나리오 · 행동 · 기대 결과 · 근거 · 실제 결과 · 판정
- 근거는 D-번호다. 번호는 v0.5.0 문서에서 이어서 붙였다 (BR-118 다음이 BR-119).
- 화면만으로 볼 수 없는 줄은 행동에 "개발자 도구" 또는 "터미널"을 적었다.
- 비밀 값(DB 주소 · AI 키)은 확인하는 사람도 화면과 채팅에 옮겨 적지 않는다. 이름이 있는지만 본다.
- 실제 결과와 판정 열은 검수하면서 채운다. 아직 검수 전이라 `-` 와 `미검수` 로 두었다.
- 판정 값은 `통과 / 차이 / 발견 기록` 중 하나다. 검수 전에는 `미검수` 다.
