# SCENARIO-REVIEW: 냉장고 관리 웹 앱

검수자가 화면에서 눈으로 확인할 시나리오 표다. v1.0.0 에서 **새로 생긴 것(배포)만** 넣었다 (R-047, US-044). 식품 등록 · 기록 · 달력 같은 이어받은 기능은 v0.5.0 검수에서 이미 확인해 다시 쓰지 않았다. 운영 주소에서 같은 기능이 같게 동작하는지만 SC-155 한 줄로 본다.
근거: [PRD.md](../../../../PRD.md), [DECISIONS.md](../../../../DECISIONS.md), [ARCHITECTURE.md](../../../../ARCHITECTURE.md) (모두 v1.0.0). 이전 버전의 같은 문서는 `docs/version/0.5.0/product-review/` 에 있다.

## 읽는 법

- 열: 번호 · 시나리오 · 행동 · 기대 결과 · 근거 · 실제 결과 · 판정
- 근거는 스토리 번호(US-), 결정 번호(D-), 질문 번호(OQ-)다.
- 번호는 v0.5.0 문서에서 이어서 붙였다 (SC-152 다음이 SC-153).
- 모든 줄은 **내 컴퓨터가 아니라 배포한 운영 주소**에서 본다.
- 실제 결과와 판정 열은 검수하면서 채운다. 이번 검수에서는 모든 줄을 기대 결과대로 동작했다고 적고 `통과` 로 판정했다.
- 판정 값은 `통과 / 차이 / 발견 기록` 중 하나다. 검수 전에는 `미검수` 였다.
