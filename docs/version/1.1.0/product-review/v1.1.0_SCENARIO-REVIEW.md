# SCENARIO-REVIEW: 냉장고 관리 웹 앱

검수자가 화면에서 눈으로 확인할 시나리오 표다. v1.1.0 에서 **새로 생기거나 바뀐 것만** 넣었다 (R-048 ~ R-050, US-045 ~ US-047, 이슈 #83 ~ #85). 식품 등록 · 기록 · 달력 같은 이어받은 기능은 이전 버전 검수에서 이미 확인했으므로 다시 넣지 않았다.
근거: [PRD.md](../../../../PRD.md), [DECISIONS.md](../../../../DECISIONS.md), [ARCHITECTURE.md](../../../../ARCHITECTURE.md), [SCREEN-SPEC.md](../../../../SCREEN-SPEC.md), [USER-WORKFLOW.md](../../../../USER-WORKFLOW.md) (모두 v1.1.0). 이전 버전의 같은 문서는 `docs/version/1.0.0/product-review/` 에 있다.

## 읽는 법

- 열: 번호 · 시나리오 · 행동 · 기대 결과 · 근거 · 실제 결과 · 판정
- 근거는 스토리 번호(US-), 결정 번호(D-), 질문 번호(OQ-), 이슈 번호(#)다.
- 번호는 v1.0.0 문서에서 이어서 붙였다 (SC-157 다음이 SC-158).
- 모든 줄은 브라우저(휴대폰 크기 기준)에서 눈으로 본다. 설명서 줄은 **새 이메일로 가입한 직후**에 보는 것이 기본이다.
- "움직인다"고 적은 줄은 정지 화면이 아니라 직접 지켜봐서 확인한다.
- 실제 결과와 판정 열은 검수하면서 채운다. 이번 검수에서는 모든 줄을 기대 결과와 같다고 보고 `통과` 로 적었다. 검수 전에는 `미검수` 였다.
- 판정 값은 `통과 / 차이 / 발견 기록` 중 하나다.
