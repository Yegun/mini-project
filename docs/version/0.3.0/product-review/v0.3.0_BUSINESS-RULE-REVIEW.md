[DECISIONS.md](../기초문서/v0.3.0_DECISIONS.md)의 유효한 결정마다 한 줄씩, [SCENARIO-REVIEW.md](v0.3.0_SCENARIO-REVIEW.md)와 같은 열로 정리한 검수 표다. 이 문서를 쓰면서 코드는 읽지 않았다.
참고: [USER-WORKFLOW.md](../기초문서/v0.3.0_USER-WORKFLOW.md), [API-SPEC.md](../설계_문서/v0.3.0_API-SPEC.md), [DATA-MODEL.md](../설계_문서/v0.3.0_DATA-MODEL.md), [SCREEN-SPEC.md](../설계_문서/v0.3.0_SCREEN-SPEC.md), [prd.md](../기초문서/v0.3.0_PRD.md) (모두 v0.3.0). 이전 버전의 같은 문서는 `docs/version/0.2.0/product-review/` 에 있다.

## 읽는 법

- 열: 번호 · 시나리오 · 행동 · 기대 결과 · 근거 · 실제 결과 · 판정
- 시나리오 열에는 확인할 결정의 이름을 적었다. 근거는 D-번호이고, PRD 에서 온 부분은 OQ-번호로 표시했다.
- 번호는 위에서부터 순서대로 붙였다(BR-01, BR-02 …). 어떤 결정인지는 근거 열의 D-번호로 찾는다.
- 이번 표는 **v0.3.0 에서 유효한 결정**만 넣었다. 폐기되었거나 이번에 만들지 않는 결정은 표에서 뺐고, 맨 아래 "표에서 뺀 결정"에 모았다.
- 실제 결과와 판정 열은 2026-11-02 ~ 03 검수로 채웠다. 검수 방법과 한계는 맨 아래 "검수 기록"에 있다.
- 판정 값은 `통과 / 차이 / 발견 기록` 중 하나다.
- 화면만으로 볼 수 없는 줄은 행동에 "개발자 도구" 또는 "DB"를 적었다. 그 도구를 쓸 수 없으면 판정을 `발견 기록` 으로 둔다.
- v0.2.0 에서 이어받은 줄(D-002 ~ D-035)은 처리한 날짜 · 계정 칸이 생긴 점, 되돌리기가 생긴 점, 클라우드 DB 로 바뀐 점에 맞게 고쳤다.
