# BUSINESS-RULE-REVIEW: 냉장고 관리 웹 앱

[DECISIONS.md]의 결정(D-001~D-100)마다 한 줄씩, [SCENARIO-REVIEW.md]와 같은 열로 정리한 검수 표다. 이 문서를 쓰면서 코드는 읽지 않았다.
참고: [prd.md], [USER-WORKFLOW.md], [API-SPEC.md], [DATA-MODEL.md], [SCREEN-SPEC.md].

## 읽는 법

- 열: 번호 · 시나리오 · 행동 · 기대 결과 · 근거 · 실제 결과 · 판정
- 시나리오 열에는 확인할 결정의 이름을 적었다. 근거는 D-번호이고, PRD 의 열린 질문은 OQ-번호, 다른 기준 문서에만 정해진 내용은 "SCREEN-SPEC 11.1"처럼 문서와 절로 적었다.
- 번호는 위에서부터 순서대로 붙였다. 어떤 결정인지는 근거 열의 D-번호로 찾는다.
- 뺀 결정: D-012 · D-017 · D-036 · D-037 (폐기. D-017 은 D-064, D-037 은 D-091 로 대체), D-019 (확인할 것이 없음), D-089 (유효 상태가 Later), D-099 ("막지 않는다"는 결정이라 D-043 줄과 같음).
- 판정 값은 `통과 / 차이 / 발견 기록` 중 하나다. 
- 화면만으로 볼 수 없는 줄은 행동에 "개발자 도구" 또는 "DB(PostgreSQL)"를 적었다. 그 도구를 쓸 수 없으면 판정을 `발견 기록` 으로 둔다.
