# USER-WORKFLOW — 냉장고 관리 웹 앱 사용자 흐름

> 근거: [prd.md](v0.3.0_PRD.md) v0.3.0 · [DECISIONS.md](v0.3.0_DECISIONS.md) (D-번호). 이 문서만 읽어도 사용자가 앱에서 **무엇을 하고, 화면에서 무엇이 보이는지** 알 수 있게 썼다.
> 시나리오 하나는 사용자가 한 가지 일을 끝내는 흐름이다. 괄호의 US·D·OQ 번호가 근거다.
> 문구는 구현 단계에서 쉬운 말로 정한다 (OQ-03).

## 0. 공통 약속 (모든 시나리오에 적용)

| 약속 | 내용 | 근거 |
|---|---|---|
| 로그인 | 로그인해야 쓸 수 있다. 로그인하지 않았으면 어느 화면을 열어도 로그인 화면이 보인다. 내 식품만 보이고, 다른 사람의 식품은 어디에도 보이지 않는다 | US-012, D-059, D-061 |
| 로그인 유지 | 마지막으로 앱을 쓴 뒤 30분 동안 유지된다. 한 계정으로 휴대폰과 컴퓨터에서 동시에 쓸 수 있고, 한쪽을 로그아웃해도 다른 쪽은 유지된다 | D-052, D-053, D-054 |
| 처음 보이는 화면 | 앱을 켜거나 로그인하면 **홈**이 가장 먼저 보인다 | D-081 |
| 아래 탭 | 로그인 화면을 뺀 모든 화면 맨 아래에 **홈 · 기록** 탭이 있다. 지금 있는 탭은 눈에 띄게 표시된다 | US-016, D-079, D-080 |
| 상태 색 | 여유 🟢 초록 / 주의 🟡 노랑 / 임박 🔴 빨강 / 지남 ⚫ 검정. 홈과 기록이 같은 색을 쓴다 | US-008, D-014 |
| "오늘" | 서버 시계의 한국 시간이다. 날짜는 한국 시간 0시에 바뀐다 | D-087, D-088 |
| 날짜 표시 | "26년 10월 30일(금)" 모양으로 보인다 | D-031 |
| 입력 검사 | 화면이 먼저 알려 주고, 최종 판단은 API 가 한다. 입력칸 옆에 안내가 보이고 저장되지 않는다 | D-010, OQ-03 |
| 실패하면 | 쉬운 오류 메시지가 화면 위에 보인다. 입력한 내용은 그대로 남고, 아무것도 바뀌지 않으며, 다시 시도할 수 있다 | OQ-04 |
| 확인 창 | 삭제할 때와, 입력하다가 탭을 눌러 이동할 때 확인 창이 뜬다 | OQ-06, D-083 |
| 오프라인 | 인터넷이 없으면 쓸 수 없다 | D-040 |
| 중복 클릭 | 저장·등록·수정·삭제·다 먹음·버림·되돌리기·가입·로그인 버튼은 처리가 끝날 때까지 다시 누를 수 없다. 연타해도 요청은 한 번만 간다. 끝나거나 실패하면 다시 누를 수 있게 돌아온다 | OQ-48, D-100 |

## 1. 처음 가입한다 (US-012)

**전제:** 아직 계정이 없다. 로그인 화면이 보이고 아래 탭은 없다.

| 순서 | 사용자가 하는 일 | 화면에서 보이는 것 |
|---|---|---|
| 1 | '새 계정 만들기'를 누른다 | 이메일·비밀번호를 적는 칸 |
| 2 | 이메일과 비밀번호를 적고 가입을 누른다 | 이메일은 @ 와 점이 있는 모양, 비밀번호는 8자 이상이고 영문·숫자·특수문자를 모두 포함해야 한다 (D-046, D-047, D-096) |
| 3 | — | 가입되고 로그인된 상태로 **홈**이 보인다 (D-081). 처음 가입한 계정이면 기존 식품이 자동으로 옮겨져 홈에 보인다. 아니면 식품이 없어서 안내 문구와 식품 등록 버튼이 보인다 (D-042, D-043, D-044) |

**예외**

| 상황 | 화면에서 보이는 것 | 근거 |
|---|---|---|
| 비밀번호가 규칙에 맞지 않음 | "비밀번호는 8자 이상이고 영문·숫자·특수문자를 모두 넣어 주세요." 가입되지 않는다 | D-047 |
| 이미 가입된 이메일 | "이미 가입된 이메일이에요." 가입되지 않는다 | D-058 |
| 기존 식품을 옮기다 실패 | 가입과 로그인은 된다. 옮기기는 전부 취소되어 일부만 옮겨진 채 남지 않고, 첫 계정이 다음에 로그인할 때 다시 시도한다 | D-097 |

## 2. 로그인한다 (US-012)

**전제:** 계정이 있고 로그인 화면이 보인다.

| 순서 | 사용자가 하는 일 | 화면에서 보이는 것 |
|---|---|---|
| 1 | 이메일과 비밀번호를 적고 로그인을 누른다 | — |
| 2 | — | **홈**이 보인다. 내가 등록한 식품만 보인다 (D-081, D-061) |

**예외**

| 상황 | 화면에서 보이는 것 | 근거 |
|---|---|---|
| 이메일이나 비밀번호가 틀림 | "이메일 또는 비밀번호가 맞지 않아요." 어느 쪽이 틀렸는지는 알려 주지 않는다. 틀려도 횟수 제한은 없다 | D-057, D-049 |
| 비밀번호를 잊음 | 비밀번호 찾기·변경은 이번에 없다 | D-050 |

## 3. 로그아웃하거나 30분이 지난다 (US-012)

| 상황 | 사용자가 하는 일 | 화면에서 보이는 것 | 근거 |
|---|---|---|---|
| 로그아웃 | 로그아웃을 누른다 | 로그인 화면으로 간다. 이 기기만 로그아웃되고, 다른 기기는 로그인된 채로 남는다. 다시 로그인하기 전에는 식품이 보이지 않는다 | D-054, D-060 |
| 30분 동안 쓰지 않음 | 앱을 다시 쓰려 한다 | 로그인 화면으로 간다. 입력하던 내용은 사라진다. 다시 로그인하면 **홈**으로 간다 | D-052, D-055, D-056 |
| 로그인하지 않은 채 주소를 직접 열기 | 홈이나 기록의 주소를 직접 쓴다 | 로그인 화면으로 간다 | D-059 |

## 4. 홈을 본다 (US-007, US-008)

**전제:** 로그인했다. 홈 탭이 선택되어 있다.

| 순서 | 사용자가 하는 일 | 화면에서 보이는 것 |
|---|---|---|
| 1 | 홈을 연다 | **이번 주 7일**(일요일 시작) 막대 달력. 식품마다 구매일부터 기한까지 가로 막대, 오늘 세로선 |
| 2 | 막대를 본다 | 이번 주를 넘는 막대는 시작과 끝이 잘려 이번 주 부분만 보인다. 막대 색이 상태를 나타낸다 (여유 6일 이상 / 주의 3~5일 / 임박 0~2일 · 기한 당일 포함 / 지남 기한 다음 날부터) |
| 3 | 달력 아래 목록을 본다 | 모든 식품이 같은 색 띠와 남은 날·지난 날 글자로 보인다. 기한이 임박한 순이고, 기한이 같으면 구매일이 이른 것이 먼저, 그것도 같으면 이름순이다 |
| 4 | 막대나 목록의 식품을 누른다 | 식품 상세 화면으로 간다 (시나리오 7) |

**알아 둘 것**

- 지난 지 4일 이상인 식품은 **달력에서만** 빠지고 목록에는 남는다. 처리할 때까지 목록에 남는다 (D-014).
- 다 먹음·버림으로 처리한 식품은 홈에 나오지 않는다 (D-091).
- 같은 이름의 식품을 여러 번 사서 따로 둘 수 있다 (D-030).

**예외**

| 상황 | 화면에서 보이는 것 | 근거 |
|---|---|---|
| 식품이 하나도 없음 | 안내 문구와 식품 등록 버튼 | OQ-05 |
| 식품을 불러오지 못함 | 쉬운 오류 메시지가 화면 위에 보인다 | OQ-04 |

## 5. 규칙표에서 골라 식품을 등록한다 (US-001)

**전제:** 홈에서 식품 등록 버튼을 눌렀다.

| 순서 | 사용자가 하는 일 | 화면에서 보이는 것 |
|---|---|---|
| 1 | 식품 이름을 검색한다 | 이름이나 별칭에 검색어가 들어 있는 식품 후보 (예: "양" → 양파, 양배추). 오타 보정은 없다 (D-035) |
| 2 | 후보에서 식품을 고른다 | 그 식품의 **기본 보관 방법이 미리 선택**된다. 그 식품에 쓸 수 없는 보관 방법은 흐리게 보이고 누를 수 없다 (D-005) |
| 3 | 수량과 단위를 적는다 | 수량은 0보다 큰 숫자(소수 둘째 자리까지). 단위는 글자로 직접 적는다 (예: 1봉, 500g, 3개) (D-027) |
| 4 | 구매일을 정한다 | 기본은 오늘. 미래 날짜도 가능하다 |
| 5 | 보관 방법을 바꿀 수 있다 | 고른 방법에 맞춰 권장 기한이 계산된다 |
| 6 | 등록을 누른다 | **홈**으로 돌아가고 식품이 막대로 나타난다. 권장 기한은 구매일 + 그 보관 방법의 기간이다 |

**예외**

| 상황 | 화면에서 보이는 것 | 근거 |
|---|---|---|
| 검색 결과가 없음 | 결과가 없다는 표시와 함께 직접 등록으로 갈 수 있다 (시나리오 6) | US-001 |
| 수량이나 단위가 비었음 / 수량이 0 이하·숫자가 아님 | 등록되지 않고 입력칸 옆에 안내가 보인다 | US-001 |
| 저장에 실패 | 쉬운 오류 메시지가 화면 위에 보이고 입력한 내용은 그대로 남는다 | OQ-04 |
| 입력하다가 아래 탭을 누름 | "입력한 내용이 사라진다"는 확인 창. 입력한 것이 없으면 확인 창 없이 이동한다 | D-083, D-084 |

## 6. 목록에 없는 식품을 직접 등록한다 (US-003)

**전제:** 검색 결과가 없어서 직접 등록으로 왔다.

| 순서 | 사용자가 하는 일 | 화면에서 보이는 것 |
|---|---|---|
| 1 | 이름과 보관 방법(상온·냉장·냉동 모두 가능)을 정한다 | — |
| 2 | 수량·단위·구매일을 적는다 | 시나리오 5 와 같다 |
| 3 | 기한을 **날짜로 고르거나, 며칠 뒤인지 숫자로** 적는다 | "며칠 뒤"는 구매일 + N일이다 (D-002) |
| 4 | 등록을 누른다 | **홈**으로 돌아가고, 직접 적은 기한의 막대가 나타난다 |

**알아 둘 것:** 직접 등록한 식품은 **내 계정에만** 있다. 공통 규칙표에는 더해지지 않고 다른 계정에서는 보이거나 검색되지 않는다 (D-092).

**예외**

| 상황 | 화면에서 보이는 것 | 근거 |
|---|---|---|
| 기한이 비었음 / 오늘보다 이전 날짜 | 등록되지 않고 안내가 보인다 | US-003 |
| 기한이 구매일보다 앞섬 | 등록되지 않고 안내가 보인다 | D-003 |
| 저장에 실패 | 쉬운 오류 메시지, 입력한 내용은 그대로 | OQ-04 |

## 7. 홈에서 식품 상세를 연다

| 순서 | 사용자가 하는 일 | 화면에서 보이는 것 |
|---|---|---|
| 1 | 홈의 막대나 목록에서 식품을 누른다 | 식품 상세. 이름·구매일·수량·단위·보관 방법·기한이 보인다 |
| 2 | 여기서 수정(시나리오 8), 보관 방법 바꾸기(9), 다 먹음·버림(10), 삭제(11)를 할 수 있다 | — |
| 3 | 뒤로 간다 | **바로 전에 보던 화면**(홈 또는 기록)으로 돌아간다 (D-085) |

**예외:** 없는 식품이거나 이미 처리된 식품이거나 **다른 계정의 식품**이면 똑같이 "없는 식품"처럼 쉬운 오류 메시지가 보인다. 그 식품이 있는지 알려 주지 않는다 (D-008, D-063).

## 8. 식품 정보를 고친다 — 이름, 구매일, 수량·단위 (US-004)

**전제:** 식품 상세 화면이다.

| 순서 | 사용자가 하는 일 | 화면에서 보이는 것 |
|---|---|---|
| 1 | 이름·구매일·수량·단위 중 고칠 것을 바꾼다 | — |
| 2 | 저장을 누른다 | 아래 표대로 기한이 정해지고 **홈**으로 간다. 막대와 색이 바뀐 대로 보인다 (D-020) |

| 바뀐 것 | 결과 | 근거 |
|---|---|---|
| 구매일 | 기한이 구매일이 움직인 일수만큼 같이 옮겨진다. **직접 적은 기한은 그대로.** 구매일은 미래 날짜도 가능하다 | D-024 |
| 이름 → 규칙표에 있는 이름 | 규칙표 기준으로 기한을 다시 계산한다. 직접 등록 식품이어도 마찬가지이고, 지금까지 쓴 수명 비율을 이어받는다 | D-004, D-026 |
| 이름 → 규칙표에 없는 이름 | **기한을 다시 적으라는 칸**이 같은 화면에 나타나고, 기한을 적어야 저장된다. 기한은 오늘보다 과거일 수 없다 | OQ-10, OQ-11 |
| 수량·단위 | 바뀐 수량·단위만 보인다. 기한과 상태는 그대로 | D-027 |

이름과 구매일을 한 번에 고치면 이름 규칙을 먼저 적용하고 그 기한에 구매일 이동을 적용한다 (D-026).

**예외**

| 상황 | 화면에서 보이는 것 | 근거 |
|---|---|---|
| 이름이 비었음 / 수량이 0 이하·숫자가 아님 | 저장되지 않고 안내가 보인다 | US-004 |
| 구매일을 직접 적은 기한보다 뒤로 바꿈 | 저장되지 않고 안내가 보인다 | D-003 |
| 이미 기한이 지난 식품을 규칙표에 없는 이름으로 바꿈 | 바꿀 수 없다는 안내가 보인다 | OQ-11 |
| 저장에 실패 | 쉬운 오류 메시지, 입력한 내용은 그대로 | OQ-04 |

## 9. 보관 방법을 바꾼다 (US-005)

**전제:** 식품 상세 화면이다.

| 순서 | 사용자가 하는 일 | 화면에서 보이는 것 |
|---|---|---|
| 1 | 보관 방법을 다른 것으로 바꾸고 저장을 누른다 | 쓸 수 없는 방법은 흐리게 보여 고를 수 없다 (D-005) |
| 2 | — | 새 기한이 정해지고 **홈**으로 간다 (D-020). 막대와 색이 바뀐 대로 보인다 |

| 식품 | 결과 | 근거 |
|---|---|---|
| 규칙표 식품 | 새 남은 기간 = (1 − 지금까지 보관한 기간 ÷ 지금 방법의 최대 기간) × 새 방법의 최대 기간. 소수 날짜는 내림. 구매일이 미래이면 보관한 기간은 0일 | D-004, D-006, D-022 |
| 직접 등록 식품 | 계산할 규칙표가 없으므로 **기한을 다시 적으라는 칸**이 나타난다. 기한은 오늘보다 과거일 수 없다 | D-023 |
| 이미 기한이 지난 식품 | 같은 식으로 계산한다. 새 기한이 오늘보다 뒤가 되면 바뀌고 더 이상 지남이 아니다. 계산 결과가 음수이거나 새 기한이 오늘보다 뒤가 되지 않으면 바꿀 수 없고 안내가 보인다 | D-006 |
| 같은 보관 방법 | 기한 그대로 성공 처리한다 | — |

**예외:** 저장에 실패하면 쉬운 오류 메시지가 보이고 입력한 내용은 그대로 남는다 (OQ-04).

## 10. 다 먹었거나 버렸다 (US-011)

**전제:** 식품 상세 화면이다.

| 순서 | 사용자가 하는 일 | 화면에서 보이는 것 |
|---|---|---|
| 1 | '다 먹음' 또는 '버림'을 누른다 | 처리 확인 |
| 2 | — | **홈**으로 간다. 식품이 목록에서 빠진다. 그날이 **처리한 날짜**로 저장된다 (D-064). 마지막 식품이면 안내 문구와 식품 등록 버튼이 보인다 |

**알아 둘 것**

- 처리한 식품은 데이터로 남아 **기록 화면**에서 숫자와 목록으로 볼 수 있다 (시나리오 12).
- 홈에서는 되돌릴 수 없다. 잘못 눌렀으면 기록 화면에서 되돌린다 (시나리오 13, D-072).

**예외:** 처리에 실패하면 쉬운 오류 메시지가 보이고 아무것도 바뀌지 않는다 (OQ-04).

---

## 11. 식품을 삭제한다 (US-006)

**전제:** 식품 상세 화면이다. 삭제는 잘못 넣은 식품을 없애는 일이다.

| 순서 | 사용자가 하는 일 | 화면에서 보이는 것 |
|---|---|---|
| 1 | 삭제를 누른다 | **확인 창**이 보인다 (OQ-06) |
| 2 | 확인한다 | **홈**으로 간다. 식품이 완전히 사라지고 **기록에서도 지워진다.** 되돌릴 수 없다 (D-013, D-078) |
| 2′ | 취소한다 | 아무것도 바뀌지 않는다 |

**예외**

| 상황 | 화면에서 보이는 것 | 근거 |
|---|---|---|
| 마지막 식품을 삭제함 | 홈에 안내 문구와 식품 등록 버튼이 보인다 | OQ-05 |
| 삭제에 실패 | 쉬운 오류 메시지가 보이고 아무것도 바뀌지 않는다 | OQ-04 |

버림과 다르다. 버림은 기록에 남고, 삭제는 기록에서도 지워진다 (D-070).

---

## 12. 기록을 본다 (US-013)

**전제:** 로그인했다.

| 순서 | 사용자가 하는 일 | 화면에서 보이는 것 |
|---|---|---|
| 1 | 아래 탭의 '기록'을 누른다 | 기록 화면. 숫자 다섯 가지가 보인다 (모두 내 식품만) |
| 2 | 숫자를 본다 | ① **다 먹음** 수 — 올해와 이번 달 / ② **버림** 수 — 올해와 이번 달 / ③ **현재 총 식품 종류** — 지금 냉장고에 있는 식품이 몇 종류인지(같은 이름은 한 종류) / ④ **보관 상태별 식품 수** — 상온·냉장·냉동 / ⑤ **식품 상태별 식품 수** — 여유·주의·임박·지남 (색은 홈과 같다) |
| 3 | 아래로 내려 처리한 식품 목록을 본다 | 다 먹음과 버림을 나눠서, 전체를, 최근 처리한 순으로 보인다 (D-073, D-074) |

**알아 둘 것**

- "올해·이번 달"은 처리한 날짜 기준이고, 서버 한국 시간으로 센다 (D-066).
- 삭제한 식품은 어떤 숫자에도 들어가지 않는다 (D-070).
- 로그인이 없던 때 처리한 기존 식품은 옮겨 온 날을 처리한 날로 센다 (D-045).

**예외**

| 상황 | 화면에서 보이는 것 | 근거 |
|---|---|---|
| 다 먹음·버림·현재 식품이 모두 없음 | 모든 숫자가 0 이고 안내 문구와 식품 등록 버튼이 함께 보인다 | D-071 |
| 숫자를 불러오지 못함 | 쉬운 오류 메시지가 화면 위에 보인다 | OQ-04 |

---

## 13. 잘못 처리한 식품을 홈으로 되돌린다 (US-015)

**전제:** 기록 화면이다. 처리한 식품 목록에 되돌릴 식품이 있다.

| 순서 | 사용자가 하는 일 | 화면에서 보이는 것 |
|---|---|---|
| 1 | 처리한 식품 목록에서 식품을 고르고 '홈으로 되돌리기'를 누른다 | — |
| 2 | — | 식품이 목록에서 빠지고, 기록 숫자(올해·이번 달)에서도 빠진다. 홈에는 다시 나타난다 |

| 상황 | 결과 | 근거 |
|---|---|---|
| 보통 | 이름·수량·단위·구매일·보관 방법·기한은 처리하기 전 그대로. 처리한 날짜는 지워진다 | D-075, D-076 |
| 기한이 지난 뒤 처리했던 식품 | 되돌리면 기한과 오늘 날짜로 다시 판정해 ⚫ 지남으로 보이고, 처리할 때까지 목록에 남는다 | D-077 |
| 삭제한 식품 | 기록에도 없으므로 되돌릴 수 없다 | D-078 |

**예외**

| 상황 | 화면에서 보이는 것 | 근거 |
|---|---|---|
| 처리한 식품이 하나도 없음 | 되돌릴 식품이 없다는 안내 | US-015 |
| 되돌리기에 실패 | 쉬운 오류 메시지가 보이고 아무것도 바뀌지 않는다 | OQ-04 |

## 14. 아래 탭으로 오간다 (US-016)

| 순서 | 사용자가 하는 일 | 화면에서 보이는 것 | 근거 |
|---|---|---|---|
| 1 | 아래 탭의 '기록'을 누른다 | 기록 화면. 기록 탭이 눈에 띄게 표시된다 | D-079 |
| 2 | '홈'을 누른다 | 홈 화면 | D-079 |
| 3 | 지금 있는 탭을 다시 누른다 | 아무 일도 없다 | D-082 |
| 4 | 식품 등록·수정 화면에서 입력하다가 탭을 누른다 | "입력한 내용이 사라진다"는 확인 창. 확인하면 이동하고 입력은 사라지며, 취소하면 그 화면에 남는다. 입력한 것이 없으면 확인 창 없이 바로 이동한다 | D-083, D-084 |
| 5 | 식품 상세 같은 하위 화면에서 뒤로 간다 | 바로 전에 보던 화면(홈 또는 기록) | D-085 |

**예외:** 탭을 눌렀는데 화면을 열지 못하면 쉬운 오류 메시지가 화면 위에 보인다. 지금 있던 화면은 그대로 남고, 같은 탭을 다시 눌러 다시 시도할 수 있다 (D-086).

## 15. 실패했을 때

모든 실패는 같은 방식으로 알린다 (D-008, OQ-04).

| 상황 | 화면에서 보이는 것 | 근거 |
|---|---|---|
| 입력 규칙 위반 (빈 값, 수량 0 이하, 과거 기한, 구매일이 기한보다 뒤 등) | 입력칸 옆에 안내. 저장되지 않는다. 입력한 내용은 그대로 | D-010 |
| 저장·삭제·처리·되돌리기 실패 | 쉬운 오류 메시지가 화면 위에 보인다. 입력한 내용은 그대로이고 아무것도 바뀌지 않는다. 버튼은 다시 누를 수 있다 | OQ-04 |
| 목록·기록을 못 불러옴 | 같은 오류 메시지 | OQ-04 |
| 없는 식품·이미 처리된 식품·다른 계정의 식품 | 모두 같은 "찾을 수 없는 식품" 메시지. 남의 식품이 있는지 알려 주지 않는다 | D-008, D-063 |
| 쓸 수 없는 보관 방법 | 흐리게 보여 고를 수 없다 | D-005 |
| 기한을 다시 적어야 함 | 실패가 아니다. 같은 화면에 기한 입력칸이 열린다 | OQ-09, OQ-10 |
| 로그인 안 함 · 30분 만료 | 로그인 화면으로 간다. 입력하던 내용은 사라진다 | D-055, D-059 |
| 로그인 틀림 | "이메일 또는 비밀번호가 맞지 않아요." | D-057 |
| 인터넷이 없거나 서버에 닿지 못함 | 같은 쉬운 오류 메시지. 오프라인 사용은 없다 | D-040 |

- 계속 실패하면 같은 오류 메시지가 계속 보인다. 문의 방법 같은 추가 안내는 이번 범위 밖이다.
