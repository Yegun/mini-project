# BUSINESS-RULE-REVIEW: 냉장고 관리 웹 앱

[DECISIONS.md]의 결정(D-001~D-037)마다 한 줄씩, [SCENARIO-REVIEW.md]와 같은 열로 정리한 검수 표다. 이 문서를 쓰면서 코드는 읽지 않았다.
참고: [USER-WORKFLOW.md], [API-SPEC.md], [DATA-MODEL.md], [SCREEN-SPEC.md].

## 읽는 법

- 열: 번호 · 시나리오 · 행동 · 기대 결과 · 근거 · 실제 결과 · 판정
- 시나리오 열에는 확인할 결정의 이름을 적었다. 근거는 D-번호이고, 아직 정해지지 않은 부분은 OQ-번호로 표시했다.
- 번호는 위에서부터 순서대로 붙였다. 어떤 결정인지는 근거 열의 D-번호로 찾는다.
- BR-(결정 번호)다. BR-01 은 D-001 이다.
- 판정 값은 `통과 / 차이 / 발견 기록` 중 하나다. 
- 화면만으로 볼 수 없는 줄은 행동에 "개발자 도구" 또는 "DB 파일"을 적었다. 그 도구를 쓸 수 없으면 판정을 `발견 기록` 으로 둔다.
